## First-time setup

### 1. Copy environment file
```bash
cp .env.example .env
```
Edit `.env` and set real values for `POSTGRES_PASSWORD`, `AUTH_DB_PASSWORD`, etc.
Never commit `.env` — it's gitignored.

### 2. Generate JWT signing keys
```bash
chmod +x scripts/generate_jwt_keys.sh
./scripts/generate_jwt_keys.sh
```
This creates `secrets/jwt_private_key.pem` and `secrets/jwt_public_key.pem`.
These are mounted into containers as Docker secrets — never baked into images.

### 3. Bring up infrastructure + auth service
```bash
docker compose up -d --build
```

Check everything is healthy:
```bash
docker compose ps
```
All services should show `(healthy)`. If auth-service shows unhealthy, check logs:
```bash
docker compose logs auth-service
```

### 4. Run database migrations
```bash
docker compose exec auth-service alembic upgrade head
```

### 5. Grant restricted DB permissions
```bash
docker exec -i devbhumi-postgres psql -U devbhumi_admin -d devbhumi \
  < database/seeds/grant_permissions.sql
```

### 6. Create the first admin account
```bash
docker compose exec auth-service python -m scripts.create_admin
```
You'll be prompted for name, phone, and password interactively.

## Verifying it works

### Health check
```bash
curl http://localhost:8001/health
# {"status":"ok","service":"auth-service"}
```

### Register a tourist account
```bash
curl -X POST http://localhost:8001/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Test Tourist",
    "phone": "+919876543210",
    "password": "TestPass123",
    "role": "tourist"
  }'
```

### Log in
```bash
curl -X POST http://localhost:8001/api/v1/auth/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=+919876543210&password=TestPass123"
```
Returns `access_token` and `refresh_token`.

### Access a protected route
```bash
curl http://localhost:8001/api/v1/auth/me \
  -H "Authorization: Bearer <access_token>"
```

### Test RBAC rejection (tourist trying to hit a police-only route)
```bash
curl http://localhost:8001/api/v1/demo/police-only \
  -H "Authorization: Bearer <access_token>"
# Expect: 403 INSUFFICIENT_PERMISSIONS
```

### Logout (blacklists the token)
```bash
curl -X POST http://localhost:8001/api/v1/auth/logout \
  -H "Authorization: Bearer <access_token>"

# Try /me again with the same token — should now fail:
curl http://localhost:8001/api/v1/auth/me \
  -H "Authorization: Bearer <access_token>"
# Expect: 401 TOKEN_REVOKED
```

Interactive API docs (auto-generated by FastAPI): **http://localhost:8001/docs**

## Security model implemented so far

- **RS256 JWT** (asymmetric) — private key signs, public key verifies. No shared secret.
- **Access token**: 15 min TTL. **Refresh token**: 7 days TTL, returned in response body (move to HttpOnly cookie when frontend is built).
- **Token blacklisting**: logout adds the token's `jti` to Redis; checked on every authenticated request.
- **RBAC**: enforced via `require_role()` dependency at the route level — never inside service logic.
- **Self-registration restricted**: public `/register` can only create `tourist` or `citizen` accounts. `police`, `admin`, `emergency_team` require an existing admin (bootstrap via `create_admin.py` script for the very first one).
- **Generic login errors**: wrong password and non-existent phone return the identical error message — prevents account enumeration.
- **Restricted DB user**: `auth_svc` Postgres user has `SELECT, INSERT, UPDATE` on `users` only — no `DELETE`, no access to any future service's tables.
- **Password rules**: min 8 chars, max 72 bytes (bcrypt limit), at least one uppercase and one digit.
- **Non-root Docker container**: auth-service runs as `appuser` (uid 1001), not root.

## Known gotcha already fixed

`bcrypt==5.0.0` is incompatible with `passlib==1.7.4` (passlib reads a `bcrypt.__about__.__version__` attribute that was removed in bcrypt 5.x, and bcrypt 5.x also enforces strict 72-byte truncation). This is pinned in `requirements.txt` as `bcrypt==4.0.1`. Do not upgrade bcrypt without re-running `tests/test_security.py` first.
